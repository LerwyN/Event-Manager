# Event Manager

Event Manager, etkinlikleri keşfetmek, danışmanları incelemek ve rezervasyon işlemlerini gerçekleştirmek için tasarlanmış modern bir web projesidir.

## 🌐 Canlı Demo

**[Event Manager'ı ziyaret et](https://event-manager-lovat-alpha.vercel.app/)**

## ✨ Özellikler

- Etkinlikleri keşfetme
- Danışmanları görüntüleme
- Rezervasyon oluşturma
- Modern ve kullanıcı dostu arayüz

## 📌 Proje

Bu proje, modern ve kullanışlı bir etkinlik yönetim deneyimi sunmak amacıyla geliştirilmiştir.
